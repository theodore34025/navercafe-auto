클라우드에서 직접 로그인

아래 브라우저 화면에서 로그인과 추가 인증을 완료한 뒤 세션을 저장하세요.

원격 화면 연결

서버 터미널에서 확인한 접속 코드를 입력하세요. 네이버 비밀번호를 입력하는 칸이 아닙니다.

  1. 로그인 화면 열기
  2. 네이버 로그인·추가 인증
  3. 로그인 완료 · 세션 저장

화면을 클릭한 뒤 키보드로 입력할 수 있습니다. 한글·붙여넣기는 아래 입력 도구도 사용할 수 있습니다. 인증 요청은 네이버 화면에서 직접 완료하세요.

로그인 화면 열기를 누르면 브라우저가 표시됩니다.

입력 도구의 내용은 전송 후 지워집니다. 화면과 입력은 파일로 기록하지 않습니다. 저장된 로그인 세션은 이 서버의 게시글·댓글 작성 기능에서 사용됩니다.

접속 대기 중

사용을 마치면 원격 브라우저를 종료하세요. 조작이 없으면 15분 후 브라우저가 종료됩니다.
